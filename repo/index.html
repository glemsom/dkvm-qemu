DKVM QEMU Alpine Package Repository

Custom Alpine Linux packages for QEMU with additional patches and optimizations.

Adding the Repository

1. Import the signing key

wget -O /etc/apk/keys/signkey.rsa.pub https://glemsom.github.io/dkvm-qemu/x86_64/signkey.rsa.pub

2. Add the repository URL

echo "https://glemsom.github.io/dkvm-qemu/x86_64" >> /etc/apk/repositories

3. Install packages

apk update
apk add qemu qemu-system-x86_64

Repository Contents

Browse packages in the x86_64 directory.

  • APKINDEX.tar.gz (signed package index)
  • signkey.rsa.pub (public signing key)
